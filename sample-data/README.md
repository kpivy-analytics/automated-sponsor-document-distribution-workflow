# Sample Data

This folder contains sanitized example data used to demonstrate the Automated Sponsor Document Distribution Workflow.

## Files

### Sample_Sponsor_Distribution_Data.xlsx

This workbook represents the source data used by the Power Automate workflow.

The Excel table contains:

- SponsorName
- Email
- WorkbookFileName
- SendDate
- Status

The workflow uses the WorkbookFileName field to identify the sponsor-specific workbook that should be retrieved from a designated SharePoint folder and attached to the email.

The data in this workbook is fictional and is provided for demonstration purposes only.
