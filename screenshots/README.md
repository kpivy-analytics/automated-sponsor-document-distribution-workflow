# Screenshots

This folder contains sanitized screenshots used to demonstrate the Automated Sponsor Document Distribution Workflow.

## power-automate-workflow-overview.png

This screenshot provides a high-level view of the Power Automate workflow.

### Workflow Components

1. Manually Trigger a Flow
2. List Rows Present in a Table
3. Apply to Each
4. Get File Content Using Path
5. Send an Email (V2)

### Workflow Purpose

The workflow retrieves sponsor records from an Excel table stored in SharePoint, identifies the sponsor-specific workbook using the WorkbookFileName field, retrieves required attachments from SharePoint, and sends customized emails to project sponsors.

All screenshots have been sanitized and do not contain production data, email addresses, SharePoint URLs, or other sensitive information.
